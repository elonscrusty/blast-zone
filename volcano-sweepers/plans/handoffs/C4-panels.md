# C4 handoff: Book, Goals, Daily, Cool Down, Settings panels

1. Panels (each registers itself with PanelHost on require): `src/client/Panels/{Book,Goals,Daily,CoolDown,Settings}.luau`, ids `book` `goals` `daily` `cooldown` `settings`, menu orders 50/60/70/80/90, icons 📖 🎯 🎁 ❄️ ⚙️. The HUD keys the automatic red dots off `daily` and `cooldown`.
2. Pure view-models (every string, state, flag and layout number lives here, Lune-tested with fake profiles): `src/shared/Ui/{BookModel,GoalsModel,DailyModel,CoolDownModel,SettingsModel}.luau`, tests `tests/{book,goals,daily,cooldown,settings}_model.test.luau`. Panels only draw what the model returns.
3. Remotes sent (names and args match RemoteDefs, the server checks all): `ClaimSet <setId>`, `ClaimGoal <goalId>`, `ClaimDaily`, `CoolDown`, `Buy "sparkPerk" <perkId>`, `SetSetting <key> <bool>`. Listened: `CoolDownDone` (a green "You got N Sparks" card for 8 s).
4. Red dots: `book` (a finished set to claim) and `goals` (a goal to claim) call `Hud.setBadge` from a module-level Context that lives for the session (store watch plus a 2 s re-send, because the HUD is built after the panels load).
5. Cool Down safety: first tap on the lava button only arms it (warning card + "Not now"), the button is grey for 1 s ("Wait..."), the second tap sends `CoolDown`; arming times out after 10 s; locked = grey button + toast. All of it is `CoolDownModel.tap` and unit tested; the client cannot send without the confirm tap.
6. Daily: the day is the UTC day of `workspace:GetServerTimeNow()` (falls back to `os.time()`), through `DailyRules.plan` (the same code the server runs). It only previews; the CLAIM button is gold and enabled only when the rules say a gift is waiting, and it greys for 1.5 s after a tap.
7. Layout is decided from the panel root's virtual width (PanelHost sizes `Panel_<id>` in virtual px): landscape (>= 480) uses 5 tiles per set row, 7 day tiles in one row, 2-column cards; portrait uses 3 tiles per row, 4+3 day tiles (day 7 double wide), stacked cards. Every panel scrolls.
8. Book: undiscovered = dark "?" tile, found = rarity-coloured frame + emoji + name + count; tap = detail sheet (rarity and odds, zone, coin value, count). Legend shows the catalog odds, plus "(yours)" numbers when Treasure Luck changes them.
9. Sound hooks used: `click`, `error` (Components), `coin`, `upgrade` (silent without ids). Never opened in Studio or on a device; checked by the Lune model tests, a fake-Roblox smoke run, luau-lsp strict analysis, stylua and a rojo build. Emoji art depends on Roblox's emoji font.
10. Not done: no settings for UI scale or language, no cool-down celebration animation (world effects come from Vfx on `CoolDownDone`), the Daily dot in the HUD still uses the client clock (`os.time`).
