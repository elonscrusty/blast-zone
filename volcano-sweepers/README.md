# Volcano Sweepers

Co-op sweeping game for Roblox (working title). Up to 16 friends sweep a cartoon volcano island clean,
sell the ash, buy tools and upgrades, dodge lava burps, find treasure. Original game; inspired by the
*feel* of the co-op cleaning genre only.

Start with `plans/DESIGN.md`. Final audit + 12-step phone checklist: `plans/audit/FINAL-server.md`,
`plans/audit/FINAL-client.md`. Sounds are silent until ids go in `Config.Audio.ids` (`plans/AUDIO-IDS.md`).

Checks (from this folder): `stylua --check src tests`, `selene src`, `lune run tests/run`,
`rojo build default.project.json -o VolcanoSweepers.rbxl`.
